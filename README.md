# 🌐 Portfólio — Carlos Herik

Este é meu portfólio pessoal, desenvolvido para apresentar meus **projetos**, **habilidades** e **evolução como desenvolvedor front-end**.

O objetivo do site é centralizar meus trabalhos, facilitar o contato profissional e mostrar na prática o que venho estudando e construindo.

🔗 **Acesse o portfólio:**  
👉 https://herikdev.vercel.app/

---

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Deploy com Vercel

---

## 📂 Estrutura do projeto

- **Home:** apresentação pessoal
- **Projetos:** listagem dos principais projetos de estudo
- **Sobre:** breve descrição da minha trajetória
- **Contato:** links para redes profissionais

---

## 🎯 Objetivo do projeto

- Consolidar conhecimentos em React

- Ter um ponto central para compartilhamento em processos seletivos
